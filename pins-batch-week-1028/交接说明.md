```

```

**来源与有效性**：
- 从主力机 Chrome 用 Cookie-Editor 扩展导出（**明文，可用**）

**cookie 失效后的正确做法**：让用户用 Cookie-Editor 重新导一次 JSON，覆盖上述两个文件。

