Eyewear Guides

Updated October 27, 2026

Most eyewear questions that sound like shopping questions are actually physics questions wearing a price tag. Whether a thin lens is better, whether a dark lens protects, whether an expensive frame is worth it: each has an answer that follows from how lenses and eyes work, and each is measurable rather than a matter of taste. These guides collect that reasoning by topic, so you can start from the principle instead of from a product list.

Each hub opens with the decision it actually helps you make, keeps the buying pages separate from the technical ones, and links the detailed articles underneath. Where a number exists, the number is given: refractive index, Abbe number, transmission bands, pitch, prism, tolerances. Where the evidence is weaker, the article says so rather than inventing a figure.

How to use a hub

Start with the decision table at the top of each hub. It maps a situation to the property that decides it, which is usually a number you can check rather than a brand you have to trust. If your case is not in the table, read the section that governs the property in question: category for brightness, polarization for glare, tint for contrast, fit for coverage.

Every hub is written so that removing the links still leaves a complete explanation. If a page reads as a list of links with no argument between them, it is not finished, and it is worth telling us.

Where the limits are

Nothing here diagnoses. Symptoms that are new, one-sided, sudden, or accompanied by pain, flashes or a change in field belong with an optometrist or ophthalmologist, not with a guide. What the guides can do is tell you which measurements are relevant and which questions are worth asking in the chair, which shortens the appointment and improves what gets recorded.
